# Nexkosmo AAA Character Template v1

This template defines the canonical standard for character assets managed by the Nexkosmo Brain.

## Purpose
- Provide a single source of truth for AAA character assets.
- Standardise ingestion, validation, production, review and release.
- Ensure every asset is fully traceable, reproducible and reusable.

## Pipeline
Inbox → Analyse → Classify → Validate → Register → Canon Library → Reuse

## Included Specifications
- Template Manifest
- Folder Schema
- Metadata Schema
- Dependency Schema
- Provenance Schema
- Confidence Schema
- Validation Rules
- Completion Rules
- Relationship Rules
- Inbox Rules
- Approval Workflow
- Production Stages
- Engine Compatibility
- Export Rules
- Versioning Rules
- QA Rules

## Governance Principles
- Canonical assets are immutable after release.
- Every change is versioned and audited.
- Every release requires validation and QA approval.
- Export packages are derived from canonical assets and never replace them.
- All assets maintain provenance, dependency and checksum records.

This template serves as the foundation for all future character assets within the Nexkosmo Brain.
