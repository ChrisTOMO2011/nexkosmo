# Nexkosmo Brain Inbox

## Purpose
The Inbox is the canonical entry point for every asset entering the Brain.

## Processing Pipeline
1. Receive asset
2. Create inbox manifest
3. Verify checksum
4. Scan for malware
5. Extract metadata
6. Generate thumbnail/preview
7. AI analyse and tag
8. Detect duplicates
9. Discover relationships
10. Validate against schemas
11. Human review (if required)
12. Register canonical asset
13. Link into Asset Graph
14. Archive inbox record

## Inbox folders
- images/
- videos/
- audio/
- documents/
- models/
- archives/
- scans/
- rejected/
- quarantine/

## Outputs
- Canonical Asset ID
- Asset Registry record
- Graph relationships
- Search index entry
- Audit trail
