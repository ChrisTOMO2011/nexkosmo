# Nexkosmo Asset Graph Service

The Asset Graph is the canonical relationship engine for the Nexkosmo Brain.

## Responsibilities
- Build directed asset graphs.
- Resolve dependency chains.
- Detect circular dependencies.
- Traverse parent/child relationships.
- Find upstream and downstream impacts.
- Identify orphaned assets.
- Answer release readiness queries.

## Core Queries
- What depends on this asset?
- What is blocking this asset?
- Which assets are orphaned?
- Which scenes are ready?
- What breaks if this asset changes?
- Which assets are safe to release?
