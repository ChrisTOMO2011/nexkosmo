# Nexkosmo Brain roadmap

The current gate is review of the Phase 4A Pre-Production Environment Brain evidence.
Later product work must not begin until the Phase 2C foundation and Phase 3 Character
evidence are reviewed and accepted.

1. Accept the Phase 2C foundation evidence.
2. Review the Phase 3 Character migration, PostgreSQL/RLS, API, frontend and browser evidence.
3. Review the Phase 4A Environment ownership, compatibility, readiness, RLS, API,
   shared-workspace and repeated-reload evidence.
4. Validate production OIDC with the selected real identity provider.
5. Register product outbox consumers one at a time with replay and failure tests.
6. Begin Camera Gear, Lighting, Audio, VFX, Props or Vehicles only through separately approved scope.

The semantic kernel, autonomous agents, uploads, AI generation, rendering and later
workflow features remain deferred. See the [master build roadmap](../roadmap/master-build-roadmap.md)
and [phase status](../roadmap/phase-status.md).
