# Nexkosmo Brain Roadmap

## Status rule

Roadmap order is constrained by the adopted Brain containment contract. Safety, recovery, Guardian enforcement, and human-controlled rollback must be established before any production-changing autonomous self-improvement capability.

## Completed implementation areas

- Brain Kernel
- Confidence Engine
- Temporal Reasoning Engine

These labels describe implemented areas, not universal production verification. Verification status is tracked separately in `BRAIN_IMPLEMENTATION_STATUS.md` and must reflect executed evidence.

## Planned

1. Causality Engine
2. Simulation Engine
3. Memory Consolidation Engine
4. Self Reflection Engine
5. Meta Reasoning Engine
6. Safety & Recovery Engine
7. Brain Integration Layer
8. Autonomous Improvement Engine

## Autonomous Improvement gate

The Autonomous Improvement Engine may be developed experimentally before full production enablement, but it must not gain production-changing authority until Safety & Recovery, Guardian enforcement, audit, rollback, and human approval controls are independently verified.
